Events Manager App

A modern Next.js + React based Events Manager where you can add, search, sort, edit and delete events with persistent storage using LocalStorage.
It also includes a clean TailwindCSS UI, toast notifications, and confirmation modals for a smooth user experience.

🚀 Features

✅ Add Events – Create events with name & date
✅ Edit / Delete Events – Update or remove events anytime
✅ Persistent Storage – Data stored in localStorage (no database required)
✅ Search Events – Debounced search for fast filtering
✅ Sort Events – Sort by name or date easily
✅ Responsive Design – TailwindCSS styling for mobile & desktop
✅ Toast Notifications – Success/Error messages with smooth animations
✅ Confirmation Modal – Prevents accidental deletions

🛠️ Tech Stack

Next.js 15 (App Router, Client Components)

React 19

TypeScript

Tailwind CSS 4

React Hook Form – For form handling

Lucide React – For modern icons

📦 Installation

Clone the repository

git clone https://github.com/mrsanjeev4-web/Mini-Event-Manager-Page.git
cd events-manager

pnpm dev

http://localhost:3000
